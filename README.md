# Dernière lumière

Prototype d'exploration à la troisième personne fait avec Unity (6000.3.5f2).

Dernière lumière.
Zack Landry
Contrainte technique : No.22, Balise lumineuse

## Concept

Une panne a plongé une forêt dans le noir. Le joueur, avec une lampe de poche à batterie limitée, suit les lanternes qui se rallument une à une jusqu'au générateur d'une cabane.

## Contrainte technique : Balise lumineuse

Le joueur est guidé uniquement par la lumière, sans flèche ni marqueur à l'écran. Une seule balise brille à la fois. Quand le joueur entre dans sa zone, elle s'éteint et la suivante s'allume.
